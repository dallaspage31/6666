# UI Directory

Contains interface UI element images: buttons, frames, icons, health bars, and other HUD elements.

## Expected Image Formats

- **UI elements**: PNG format with transparent background (RGBA)
- **Nine-patch frames**: PNG with defined stretchable regions
- **Icons**: Square PNG (e.g., 32x32, 48x48, 64x64)
- **Health bars**: PNG with horizontal orientation

## Naming Conventions

- Buttons: `btn_{buttonName}.png` (e.g., `btn_Attack.png`, `btn_Skill.png`)
- Frames/panels: `frame_{frameName}.png` (e.g., `frame_Inventory.png`)
- Icons: `icon_{iconName}.png` (e.g., `icon_HP.png`, `icon_Mana.png`)
- Health bars: `bar_{barName}.png` (e.g., `bar_HP.png`, `bar_XP.png`)
- Miscellaneous UI: `ui_{elementName}.png` (e.g., `ui_Cursor.png`, `ui_MenuBG.png`)
