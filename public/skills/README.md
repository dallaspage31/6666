# Skills Directory

Contains ability icon images for all hero abilities and enemy skills.

## Expected Image Formats

- **Icons**: PNG format with transparent background (RGBA)
- **Recommended size**: 64x64 pixels or 128x128 pixels (square)
- **File format**: PNG for lossless transparency; WebP optionally for smaller sizes

## Naming Conventions

- Icon files: `{skillName}.png` (e.g., `Fireball.png`, `Heal.png`)
- Hero ability icons: `{heroName}_{skillName}.png` (e.g., `Knight_Strike.png`)
- Enemy skill icons: `{monsterName}_{skillName}.png` (e.g., `Goblin_Slash.png`)
- Passives/auras: `{skillName}_passive.png`
- Skill cooldown overlay: `{skillName}_cooldown.png`
