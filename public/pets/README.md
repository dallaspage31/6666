# Pets Directory

Contains sprite images for the 9 available pets.

## Expected Image Formats

- **Sprites**: PNG format with transparent background (RGBA)
- **Recommended size**: 32x32 or 64x64 pixels (square)
- **Animation frames**: Sequential PNG frames for pet animations

## Naming Conventions

- Pet sprite files: `pet_{petName}.png` (e.g., `pet_Dragon.png`, `pet_Fox.png`)
- Pet animation frames: `pet_{petName}_frame_{index}.png`
- Pet icon (HUD): `pet_{petName}_icon.png`

## Pets (9 total)

Each pet should have at least an idle sprite and optional animation frames.
