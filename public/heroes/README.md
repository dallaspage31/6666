# Heroes Directory

Contains hero sprite sheets and animation pages for all playable hero classes.

## Expected Image Formats

- **Sprite sheets**: PNG format, transparent background (RGBA)
- **Animation pages**: PNG format, each frame on a separate row or column within the sheet

## Naming Conventions

- Hero class directories use PascalCase: `Knight/`, `Mage/`, `Archer/`, `Priest/`, `Assassin/`
- Sprite sheet files: `{heroName}_sheet.png` (e.g., `Knight_sheet.png`)
- Animation frames extracted from sprite sheets by row/column index
- Icon/portrait: `{heroName}_icon.png`

## Subdirectories

- `Knight/` — Knight hero sprites and animations
- `Mage/` — Mage hero sprites and animations
- `Archer/` — Archer hero sprites and animations
- `Priest/` — Priest hero sprites and animations
- `Assassin/` — Assassin hero sprites and animations
